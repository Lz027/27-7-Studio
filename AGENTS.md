# Agent Instructions & Project Guidelines

> [!IMPORTANT]
> **Git History Safeguards**: Avoid rewriting published git history (force pushing or rebasing/amending/squashing commits that are already pushed). Keep the repository in a clean and working state on every commit.

> [!NOTE]
> **Technical & Code Autonomy**: The agent is empowered to exercise its best technical judgment regarding code decisions, architecture, and refactoring. While recommendations may be suggested when appropriate, the agent has full authorization to make the final technical judgment for code quality, safety, and implementation details.
